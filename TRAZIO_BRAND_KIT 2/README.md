# TRAZIO Brand Kit

Asset master: SVG. PNG exports are rendered at 300 dpi equivalent; mockups are also supplied in JPG.

## Palette

| Token | HEX | RGB | CMYK |
|---|---|---|---|
| Electric Blue | `#126BFF` | 18, 107, 255 | 93, 58, 0, 0 |
| Deep Navy | `#08111F` | 8, 17, 31 | 74, 45, 0, 88 |
| Ice Grey | `#E9EEF5` | 233, 238, 245 | 5, 3, 0, 4 |
| Ink | `#0B1320` | 11, 19, 32 | 66, 41, 0, 87 |

## Fonts

Poppins for display headings and calls to action; Inter for body copy and interfaces. Use the PDF guide for logo clearance, minimum size, and misuse rules.

## Folder map

- `01_LOGO` - horizontal, stacked and monochrome master logos
- `02_SYMBOL` - stand-alone mark for compact uses
- `03_FAVICON_APP` - favicon and app icon
- `04_SOCIAL` - profile and social cover formats
- `05_BUSINESS_CARD` - front/back SVG/PNG and print PDF
- `06_WEBSITE` - hero and homepage direction
- `07_MOCKUPS` - laptop, smartphone and office-sign visualizations
- `08_BRAND_GUIDELINES` - visual guide (SVG/PNG) and print-ready PDF
- `09_EXPORTS` - stationery, email signature, pattern and duplicated master exports
